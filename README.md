# Thaity — юридические страницы

Публичные страницы приложения Thaity (iOS и Android), публикуются через GitHub Pages:

- Политика конфиденциальности: https://pavelsemenchenko.github.io/thaity-legal/privacy.html
- Удаление аккаунта и данных: https://pavelsemenchenko.github.io/thaity-legal/delete-account.html

Текст политики должен совпадать с экраном «Настройки → Политика конфиденциальности» в приложениях — менять их нужно вместе.
